# URL Checker

A simple URL checker built with TypeScript and Vite.

The application validates URLs as the user types and uses a mocked asynchronous server to check whether a URL exists and whether it is a file or folder.

## How to use

Navigate to the project directory:

`cd url-checker`

Install dependencies:

`npm install`

Run the application:

`npm run dev`

## Example URLs

- `https://example.com/file.txt`
- `https://example.com/docs/report.pdf`
- `https://example.com/images/logo.png`
- `https://example.com/folder/`
- `https://example.com/docs/`
- `https://example.com/images/`
- `https://example.com/unknown`
- `https://example.com/missing.pdf`

The application uses predefined mock data. No real server requests are made.
